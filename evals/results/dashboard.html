Saudi dust-visibility forecast — adaptive multi-agent workflow evaluation

19 test cases run against 4 systems with the same table, trial budget and target, and no LLM calls. Forecast quality is measured by one referee procedure on one shared chronological holdout (the most recent 20% of days). Outcome cases can be passed by any system; capability cases need an intermediate output or a coordination decision that a system must expose to be scored.
